# Joan
Inspired by the romans cut by Francesco Griffo, it is a tribute to the Italian style, a model to follow even in the 15th century.  
Joan is characterized by neat serifs as well as sharp terminals and is intended for books and magazines.  
The font supports the complete Latin Plus character set.  
An Italic style is now included. Most of it is generated by mechanically slanting the Roman; a growing set of letters instead use true italic constructions traced from Paolo Biagini's published italic specimen (see sources/MASTERS.md).

# Changelog
#### v1.002

* Italic: 13 lowercase letters (`a f g y k p n m h r germandbls l eng`) now use true italic constructions traced directly from Paolo Biagini's published italic specimen, replacing the mechanical shear for those letters (single-storey `a`, cursive `g`, descending `f`, etc.);
* accented/composite glyphs built on these letters (`aacute`, `gcommaaccent`, `ntilde`, ...) are reassembled around the new letterforms;
* remaining lowercase, figures, and caps/small caps are still mechanically sheared, pending separate tuning passes.

#### v1.001

* added an Italic style, generated by shearing the Roman master (see sources/MASTERS.md);
* true hand-drawn Italic letterforms are tracked separately and not yet included.

#### v1.000
* added nbspace, twosuperior, threesuperior, micro, onesuperior, onequarter, onehalf, threequarters, foursuperior, divisionslash;
* corrected path direction;
* updated v-metrics.
